### Option title

**ProdAssist**

### Objective description (paste)

Android app with manual exposure, zebras, peaking, HDMI program output, RTMP, and an Extra Cam mixer; includes a Windows companion that exposes the active phone as a virtual webcam for desktop streaming and meeting apps. Freemium with Pro and Studio tiers.

### Example pros (objective)

- Manual ISO, shutter, white balance, and focus on Android  
- Monitoring tools (histogram, zebras, peaking) and RTMP / HDMI program out  
- Windows companion for OBS, Zoom, and Teams webcam use  
- Extra Cam mixer for multi-phone setups  

### Example cons (honest)

- Android + Windows only (no iOS companion)  
- Advanced features partly behind Pro/Studio subscriptions  
- Smaller user base than DroidCam / Open Camera
